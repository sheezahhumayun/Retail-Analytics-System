### Public interface (`base.py`)
```python
class CameraState(str, Enum):   # PRD §8
    DISABLED, OFFLINE, ERROR, PROCESSING, ONLINE = ...

class VideoSource(ABC):
    def open(self) -> None                       # raises VideoSourceError on failure
    def read(self) -> tuple[bool, np.ndarray | None]
    def get_fps(self) -> float                   # source fps
    def get_resolution(self) -> tuple[int, int]  # post-resize (what downstream sees)
    def get_source_resolution(self) -> tuple[int, int]
    def get_state(self) -> CameraState           # PRD §8, forward-looking for Module 16
    def is_live(self) -> bool                    # True for RTSP/webcam, False for files
    def release(self) -> None
    # context-manager (__enter__/__exit__) + disable()/enable()
```

### Centralized concerns (in the ABC/mixin — NOT downstream)
1. **Target-FPS throttling inside `read()`**: `target_fps` (default 10) + `source_fps` → `frame_interval = max(1, round(source_fps/target_fps))`. Internal `_frame_index`; skipped frames use cheap `grab()` (no `retrieve()`/decode). This is the "every 3rd frame at 30fps" logic, owned here.
2. **Downscale long-side to 640** (CPU reality check): `cv2.INTER_AREA`; `get_resolution()` returns resized dims; no-op if already ≤ target.

### Implementations
- **FileVideoSource**: `cv2.VideoCapture(path, CAP_FFMPEG)`. `is_live()=False`. EOF returns `(False, None)`; optional `loop=True` for dev. `source_fps` from `CAP_PROP_FPS`, fallback 30.0.
- **RTSPVideoSource**: `cv2.VideoCapture(url, CAP_FFMPEG)` with `OPENCV_FFMPEG_CAPTURE_OPTIONS` for timeout (avoid hangs on dead NVRs). `is_live()=True`. N consecutive `read()` failures ⇒ exponential backoff reopen; state `ONLINE→ERROR→PROCESSING→ONLINE`. `read()` never raises for transient drops — returns `(False, None)` and keeps trying (normal NVR behavior per task).
- **WebcamVideoSource**: `cv2.VideoCapture(index)` (`CAP_DSHOW` on Windows for fast open). `is_live()=True`.

### Factory
```python
def create_video_source(spec: str | int | Path, **kwargs) -> VideoSource
```
Routes: `rtsp(s)://`/`rtmp://` → RTSP; `int` → Webcam; file path/ext → File. Downstream code never branches on source type (the seam PRD §9 requires).

### Tests (`pytest`) — run against local sample-data, no downloads

5. State transitions: `OFFLINE` → `PROCESSING` → `ONLINE` → `OFFLINE`.
