### Types (`types.py`) — PRD §10 return contract
```python
@dataclass(frozen=True, slots=True)
class Detection:
    bbox: tuple[float, float, float, float]   # (x1, y1, x2, y2) in input-frame px
    confidence: float
    class_id: int                              # always 0 (person) post-filter
    class_name: str                            # "person"
    timestamp: float                           # frame time (epoch seconds)
    camera_id: str                             # from source/caller

class DetectionBackend(str, Enum):
    ULTRALYTICS = "ultralytics"   # PyTorch
    ONNX = "onnx"                 # ONNX Runtime
```
A `Detection` carries everything PRD §10 lists (bbox, confidence, class, timestamp, camera_id). Frozen+slots for cheap, immutable downstream passing.

### Base interface (`base.py`) — swappable per PRD §10
```python
DEFAULT_CONF_THRESHOLD = 0.4   # task: start at 0.4, tune in Module 18
DEFAULT_IOU_THRESHOLD = 0.5    # NMS
PERSON_CLASS_ID = 0            # COCO "person"

class PersonDetector(ABC):
    def __init__(self, *, conf_threshold=DEFAULT_CONF_THRESHOLD,
                 iou_threshold=DEFAULT_IOU_THRESHOLD, person_only=True,
                 input_size=640): ...
    @abstractmethod
    def _raw_infer(self, frame) -> list[Detection]: ...   # no filtering
    def detect(self, frame, *, timestamp=None, camera_id="default") -> list[Detection]:
        # 1. _raw_infer -> raw detections
        # 2. filter person_only (class==0) if set
        # 3. attach timestamp (default = time.time()) + camera_id
    @abstractmethod
    def backend(self) -> DetectionBackend: ...
    @abstractmethod
    def release(self) -> None: ...
    # context manager __enter__/__exit__
```
Filtering + timestamp/camera_id stamping live in the ABC so both backends share it — implementations only do raw inference. This is the "replaceable model" seam: swapping YOLOv8n→YOLOv8s or PyTorch→ONNX changes one constructor arg, nothing downstream.

### Implementations
- **`UltralyticsDetector(model_path="yolov8n.pt", ...)`**: wraps `ultralytics.YOLO`. `detect`→`model.predict(frame, conf=, iou=, classes=[0], verbose=False, imgsz=640)`. Lazy-imports ultralytics + torch in `__init__`. Maps `Results.boxes` → `Detection`. `backend()==ULTRALYTICS`. `release()` clears the model ref.
- **`ONNXDetector(model_path="yolov8n.onnx", ...)`**: wraps `onnxruntime.InferenceSession` with `CPUExecutionProvider`. Preprocessing (letterbox resize to 640, /255, NCHW), postprocess the raw YOLO output grid (conf filter + class filter to person + XYXY decode + NMS via `cv2.dnn.NMSBoxes`). This is the fiddly part — I'll implement a clean letterbox + grid-decode + NMS pipeline. `backend()==ONNX`.

### Factory (`factory.py`)
```python
def create_detector(model_path=None, *, backend="ultralytics", **kw) -> PersonDetector
```
- `backend="ultralytics"` (default) → UltralyticsDetector; default model `yolov8n.pt`.
- `backend="onnx"` → ONNXDetector; default model `yolov8n.onnx` (auto-exports from the `.pt` if missing, via `UltralyticsDetector.export_onnx()`).
- Both accept `conf_threshold`, `iou_threshold`, `person_only`, `input_size`.

### Export helper
`UltralyticsDetector.export_onnx(path=None) -> Path` calls `model.export(format="onnx")` — used once to produce `yolov8n.onnx` for the ONNX path (per task: "export the model to ONNX ... once detection is functionally correct").

### Tests (`tests/test_detection.py`) + conftest additions
Markers: `detection` (needs model download / is slower). Run fast unit tests by default; gate the real-inference ones so `pytest` with no markers stays quick.
1. **Types**: `Detection` frozen/immutable; `DetectionBackend` values.
2. **Filtering contract (ABC, no model needed)**: subclass with a fake `_raw_infer` returning [person, car, dog] → assert `detect()` keeps only `class_id==0`, and attaches timestamp+camera_id.
3. **Factory routing**: `backend="ultralytics"`→UltralyticsDetector, `"onnx"`→ONNXDetector.
4. **Real inference (gated `@pytest.mark.detection`)**: load YOLOv8n, run on 1 frame from each sample video → assert non-empty person detections, bboxes within frame bounds, all `class_id==0`, confidences in [0,1].
5. **Parity (gated)**: ONNX vs Ultralytics on same frame → person-detection counts agree within a tolerance (ONNX is lossless per task, so they should match closely).
6. **Smoke integration (gated `slow`)**: end-to-end `VideoSource → PersonDetector` on a sample clip; count detections over N frames, assert sane.
